# V3.1 equality diversity repair

At paused checkpoint round 935, deterministic GPU diagnostics measured equality answers: familiar training pairs 30/30, existing validation pairs 3/12, and fresh diagnostic pairs 1/30. Fresh pairs span a broader number range, so that score measures both new values and a harder domain. The original held-out deficit supports limited equality generalisation despite perfect familiar-pair accuracy.

The immutable derivative G:/ctfn-text/data/v3_1_equality_v2 preserves all original split records and adds 3,000 distinct equality pairs, each with two adjacent-order contrasts: 9,000 training examples. It adds 60 disjoint contrastive triples (180 examples) to validation; the fresh diagnostic equality pairs are part of this validation set and excluded from training. Swapped-pair family checks protect existing validation/test/quarantined comparisons. The builder verifies targets and tokenizer lengths (maximum 135 for additions). An independent audit verified no new-training/held-out pair overlap and equal sampling of the three decisions.

The checkpoint is preserved before migration. Weights, optimizer and RNG remain, while the partial round restarts on the new sampling distribution. Focused comparison training uses 80% comparison practice and 20% other-skill replay. It checks routine mastery each round and all focused validation every five rounds, then the next round after a pass. Two consecutive full 100% answer/trace/format passes end focused recovery. Normal stage training and its two full promotion passes follow. Loss does not gate this recovery. SIGReg remains 0.0003 and the strict first-five-stage policy remains enabled. If focused recovery fails for 240 rounds it pauses for inspection.

The source dataset remains available. Before-diagnostic results, per-question outputs, adoption metadata and the backup checkpoint reside in the V3.1 math artifact directory. The model's progress on this new dataset has not yet established successful generalisation.
