# Paired SIGReg comparison

The production curriculum is paused at Stage 6 after round 62 and the first update of round 63. The protected `sigreg_comparison/start.specialist` copies that exact state, including optimizer and CPU/CUDA RNG. SHA256: `2454b31f87cde5bd5e8ca101546966027b19d8a9acc8da197cf30e6e954cc409`. The file is read-only and the runner verifies its hash. The earlier preparation snapshot and production checkpoint are also retained.

The experiment counts ten **full independent rounds**, numbered 1-10, from that common state. It does not treat the already-completed production update as experiment training or skip a batch based on its old cursor. Both arms draw identical 4,096-example batches with the same seed schedule beginning at production seed round 63. Sampling with replacement is unchanged. Batch semantic-ID files are saved and their hashes compared before every SIGReg round. Each arm restores the same model, optimizer and RNG, uses the same 75% active/25% prior mixture, learning rate, dropout and weight decay, and has no recovery or stage promotion.

The baseline arm runs first. After ten rounds it saves `baseline/endpoint.specialist`, evaluates all deduplicated current-stage and prior-stage validation examples, then the SIGReg arm reloads the common starting checkpoint and runs its matched ten rounds. SIGReg ends in `sigreg/endpoint.specialist`. The script writes `comparison.json` and stops; it does not replace production with either endpoint. Sealed tests are not used.

SIGReg uses the empirical characteristic-function statistic from the authors' [LeJEPA minimal example](https://github.com/galilai-group/lejepa/blob/main/MINIMAL.md). This maths adaptation uses the final normalized hidden state at the prompt SEP token, before any answer token can influence it, with no new learned projector. The additive loss is weighted cross-entropy + 0.0001 * SIGReg. There are 256 random projection directions and 17 quadrature points on [0,3], computed in float32. Projection randomness uses a dedicated generator, leaving the shared dropout RNG stream unchanged. This is one chosen coefficient and one seed, not a claim that the vision method is already validated for maths or forgetting.

Three focused tests cover finite gradients, RNG isolation, the Gaussian statistic and zero-coefficient equivalence. A real RTX 4070 backward pass on the protected model had finite gradients: CE 0.0427453, SIGReg 9.61678, weighted penalty 0.000961678. That disposable smoke check did not alter the checkpoint.
